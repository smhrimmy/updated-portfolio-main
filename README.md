# Updated Portfolio Website

## Project Overview
This is a personal portfolio website created by Prajwal D L. It showcases skills, experience, projects, and contact information in a modern, interactive, and visually appealing way.

## Technologies Used

```
+-------------------+       +------------------+       +------------------+
|    React          | <---> |  React Router    | <---> | React Query      |
+-------------------+       +------------------+       +------------------+
        |                          |                          |
        v                          v                          v
+-------------------+       +------------------+       +------------------+
| TypeScript        |       | Framer Motion    |       | React Three Fiber |
+-------------------+       +------------------+       +------------------+
        |                          |                          |
        v                          v                          v
+-------------------+       +------------------+       +------------------+
| Tailwind CSS      |       | Lucide React     |       | Vite             |
+-------------------+       +------------------+       +------------------+
```

- **React**: Frontend library for building UI components.
- **TypeScript**: Typed superset of JavaScript for better developer experience.
- **React Router**: Client-side routing.
- **React Query**: Data fetching and caching.
- **Framer Motion**: Animation library for React.
- **React Three Fiber**: 3D rendering with Three.js in React.
- **Tailwind CSS**: Utility-first CSS framework.
- **Lucide React**: Icon library.
- **Vite**: Build tool and development server.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd updated-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` (or the port Vite specifies).

## Usage

- Navigate through the portfolio sections: Home, About, Experience, Skills, Projects, Contact.
- Download the resume from the Hero section.
- Interactive 3D scene and smooth animations enhance user experience.
